# 🧸 Catálogo de Brinquedos — Frontend

Interface web de um sistema completo de catálogo de brinquedos, desenvolvida com foco em experiência do usuário, organização de código e integração com API REST.

> Projeto acadêmico com abordagem profissional, simulando um sistema real de e-commerce/catalogação com diferentes níveis de acesso.

---

# 🌐 Aplicação Online

🚀 O projeto já está publicado e acessível via navegador:

* Frontend hospedado na web
* Integrado com API REST em produção
* Comunicação em tempo real com o back-end

⚠️ O desempenho pode variar dependendo da infraestrutura do servidor (ex: planos gratuitos)

---

## 🎯 Objetivo

Desenvolver uma aplicação frontend capaz de consumir uma API REST e oferecer uma experiência fluida para:

- Navegação de produtos
- Busca e filtragem
- Visualização detalhada
- Gerenciamento de dados (admin)

---

## 🧠 Principais Aprendizados

Este projeto foi construído com foco em consolidar conceitos essenciais de desenvolvimento web:

- Separação de responsabilidades (API x UI)
- Consumo de APIs REST com `fetch`
- Manipulação dinâmica do DOM
- Controle de estado via URL (query params)
- Estruturação modular em JavaScript
- Controle de permissões no frontend

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estrutura semântica
- **CSS3** — Estilização e layout
- **JavaScript (ES6+)** — Lógica da aplicação
- **Fetch API** — Comunicação com backend

---

## 🔗 Integração com Backend

Este frontend consome uma API REST desenvolvida em Spring Boot.

---

## 🚀 Funcionalidades

### 👤 Usuário comum
- Visualizar lista de brinquedos
- Buscar por nome
- Filtrar por marca
- Acessar detalhes dos produtos

### 🔑 Administrador
- Adicionar novos brinquedos
- Editar informações existentes
- Excluir registros

---

## 🔍 Diferenciais do Projeto

- 🔄 **Filtros persistentes na URL**  
  Permite navegação sem perda de estado

- 🧭 **Roteamento simples no frontend**  
  Controle de navegação baseado em perfil (admin vs usuário)

- 🔐 **Controle de acesso no client-side**  
  Elementos são exibidos dinamicamente conforme permissão

- 🧱 **Código modularizado**  
  Facilita manutenção e escalabilidade
